# ScanContact

Échangez vos contacts professionnels et vos réseaux sociaux en **un seul scan**
de QR code. Site officiel et téléchargement de l'application Android.

👉 **Site : https://jesimel9.github.io/scancontact/**

- Application Android gratuite (Android 7 ou plus récent)
- Lisible aussi par un iPhone : la carte s'affiche en texte avec l'appareil photo
- Conçue à Abidjan, Côte d'Ivoire, par Yao Kouassi Jean Jesimel

Le code source de l'application n'est pas public.
